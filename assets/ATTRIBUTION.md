# Asset attribution

The technology icons are from [Devicon](https://github.com/devicons/devicon), downloaded from its `master` branch on 4 October 2026. The bundled `DEVICON-LICENSE.txt` preserves the project's MIT license and copyright notice.

Icons: TypeScript, JavaScript, C++, Rust, Python, Go, Java, and Kotlin. Rust's default fill was changed to `#bf4057` so it remains visible against both light and dark backgrounds. Names remain visible as native text beside each icon.

`circuit-mark.svg` is an original static mark created for this profile: a circuit-shaped A with three terminals, using a red accent drawn from the existing avatar's palette.
